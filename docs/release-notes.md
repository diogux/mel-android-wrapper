## Latest build

A lightweight native Android controller for Mitsubishi MELCloud Home.

- Power, temperature slider, supported operating modes, fan and vane controls.
- Responsive home-screen widget with controls that fill its existing box.
- Phone-based weekly schedules and energy information where supported.
- Browser OAuth login, encrypted session storage and token refresh.

### Install / update

Download **mel-android-wrapper.apk** below and open it on Android 8 or newer. Updates use the same signing identity; install over the existing app to retain its session/settings.

Phone schedules require the phone powered on, signed in and online, plus alarm access on supported Android versions. Existing Mitsubishi cloud schedules are read-only. Energy availability depends on the device. This is an unofficial, personal debug-signed sideload build; automated tests do not confirm real AC execution.

**One download, kept current.** This rolling release replaces the previous APK; source control contains no APK binaries or historical APK copies. `SHA256SUMS` verifies the download.
